### 5. ТЕХНИЧЕСКИЙ РЕГЛАМЕНТ МОДУЛЯ ГРАФИКИ (create_scenes_and_export.rb)
* **Режим «Живая камера»**: Скрипт вообще не вмешивается в ручной масштаб, зум и центрирование инженера. Он замораживает текущий ракурс с экрана (`fixed_camera_focused = view.camera`) и рендерит все кадры пиксель в пиксель.
* **Фикс черных квадратов**: Внутри цикла на каждом ряду принудительно вызывается сброс графического кэша видеокарты через `view.invalidate` перед командой полной перерисовки `view.refresh`.
* **Тайминги стабилизации**: Задержка внутри цикла установлена на уровне `sleep(0.50)` (Пауза Х2), чтобы движок Overdrive успевал прогрузить геометрию. Перед циклом — `sleep(0.40)`.
* **Логика слоев порядовки**: Для вида `:top` — строго один текущий слой ряда (`layer.visible = (row_num == current_row)`). Для изометрии `:iso` — накопительное возведение (`layer.visible = (row_num <= current_row)`). Слои `palette_` и `finish_` скрываются для четкого кадрирования, слой `untagged` всегда включен.

* **Всеядный сквозной парсер**: Метод `self.generate_html_guide` построчно читает файл сметы в кодировке `UTF-8`.
* **Автоматизация шифра и названия**: Из строки `[MODEL_TITLE] : Барбекю комплекс «У-3240-НМ»` парсер автоматически забирает полное имя на обложку, а текст внутри кавычек выделяет в переменную `project_code = "У-3240-НМ"` и подставляет её в верхние колонтитулы `.header-meta` всех страниц.

* **Сетка страниц порядовок (v77.78 - ПРАВЫЙ BADGE)**: 
  * Шапка документа делится двухколоночным флексом `.row-header-area { display: flex; justify-content: space-between; align-items: center; }`.
  * Номер ряда `<h1>Ряд №XX</h1>` располагается слева, а инфо-плашка расхода кирпича и монтажа литья `.row-badge` смещена строго **в правую сторону** и занимает `width: 78%`, чтобы длинный текст не переносился криво.

* **Формат вывода**: 64 страницы А4 Landscape, жестко заблокированы системные колонтитулы браузеров ("1/7") через CSS `@page { margin: 0; }`. Укрупненное печное литье автоматически суммируется поштучно (например, `Подвес прямой (5 шт)`). На картах материалов (Стр. 4, 5) установлен масштаб `transform:scale(1.22);` для читаемости фактур.

### 8. РЕГЛАМЕНТ ПЕЧАТИ В PDF БЕЗ ИСКАЖЕНИЙ ВЕРСТКИ
* При выводе `index.html` в печать через браузер (Ctrl+P) в системе **обязательно** выставляются параметры:
  * Поля: *«Нет»* (или *«Минимум»*), чтобы сработал `@page { margin: 0; }`.
  * Опция *«Фоновые рисунки»* (Background graphics) — **ВКЛЮЧЕНА** (иначе пропадут бежевые плашки и линовка заметок).
  * Опция *«Колонтитулы»* (Headers and footers) — **ВЫКЛЮЧЕНА** (иначе браузер напечатает системную дату и имя файла поверх шапки альбома).
